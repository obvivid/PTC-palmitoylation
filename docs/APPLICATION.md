# Application analysis

## Fixed expression contrast and rank scoring

Supply the six GEO series files and GPL570 annotation already listed in config/inputs.csv. Run modules 25 and 26 through run_analysis.R. Module 25 reads these public inputs directly and writes all tables below outputs/analysis/single_sample/tables. It derives thresholds in GSE33630 only, applies them without retuning, and records both the primary Youden and the additional development-sensitivity operating points. The contrast and rank routes are defined before transfer evaluation. The fixed background and thresholds in single_sample/ provide the corresponding individual scoring entry point.

Five-fold development evaluation holds the score definition fixed and selects thresholds in training patients. Mixing uses 24 matched GSE60542 pairs, reverses the deposited log2 scale, combines the paired signals, and transforms them back before scoring. Weights are artificial expression-signal proportions. Missing inputs and unsupported scales raise errors.

Tables S19–S21 and S27 use fixed_pipeline_results.csv, development_patient_grouped_cv.csv, synthetic_signal_mixing.csv, measurement_stress.csv and their paired source records. Figure S9 is generated by module 26. Both routes and operating points are retained in the source outputs. The raw expression profiles and generated checkpoints remain outside the source distribution.

## Exploratory learned-rule comparison

The original TCGA signature, the equal-weight single-sample contrast and the exploratory learned rule are distinct scoring definitions. The four genes are fixed. See Supplementary Methods SM11–SM12 and Supplementary Tables S22–S23 and S26.

Run modules 25,27,28,29 after acquiring the public GEO inputs. Module 25 writes `outputs/analysis/single_sample/analysis_cache.rds`; module 27 prepares four representations and evaluates the finite set of 30 candidates; module 28 exports frozen parameters and evaluates mixtures; module 29 generates Supplementary Figure S10. Module 27 repeats the full five-repeat nested comparison and can take substantial time. Earlier modules need not be rerun if their documented prerequisite outputs are available.

For an individual processed GPL570 profile, run:

```text
Rscript application_models/score_cli.R application_models/example_four_gene_input.csv result.csv
```

Inputs are deposited probe-averaged gene-level log2 values. The four frozen coefficients and cutoff are provided in application_models/learned_contrast_frozen.csv. ZDHHC6 is an algebraic reference, not an experimentally validated housekeeping gene. The example demonstrates execution, not clinical validation. Expression-rank models additionally require the whole frozen background.

Every fitted candidate and both operating points are evaluated, including transfer failures. The displayed relative-expression SVM was highlighted after inspection of the complete comparison; it was not the model chosen by development-only selection. Normal-only mixture calls and all five weights are reported. The 24 patients, rather than the 120 constructed profiles, define the independent mixture units. Mixture weights describe tissue-expression signals and are not measured tumour-cell fractions. The code includes an optional model fitted to pooled cohorts; those cohorts are training data for that object.
