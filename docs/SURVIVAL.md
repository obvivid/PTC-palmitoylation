# Exploratory survival analysis

Patient-level endpoint statuses and follow-up times in months were obtained from the cBioPortal TCGA-THCA PanCancer Atlas clinical table. Tumour scores were matched using the first 12 characters of the TCGA barcode, with one tumour per patient. For each endpoint, patients with missing score, status or follow-up, non-positive follow-up, or status outside 0/1 were excluded. Status 1 denoted an event and 0 denoted censoring. The endpoint-specific median score defined Low (score at or below the median) and High (above the median) groups; no outcome-based cut-point selection was used. Cox models used the Efron method for tied events. Hazard ratios compare High with Low; confidence intervals are 95% Wald intervals. Log-rank tests were two-sided, and Benjamini-Hochberg adjustment was applied across the four endpoints. Proportional hazards were assessed using cox.zph. The submitted analysis uses univariable models. Adding the fitted model intercept to all scores does not change the groups or survival estimates. Analyses used survival 3.8.6; step 24 of Supplementary Code 1 regenerates the endpoint summary.

Run step 08 first, then `Rscript run_analysis.R --steps=24`. The required patient clinical input is listed in config/inputs.csv. Outputs are written to outputs/analysis/survival_endpoints.csv. The bundled data/figure_tables/Supplementary_Table_S8_survival.csv contains the submitted aggregate results; no individual clinical data are bundled. Model coefficients are frozen from the diagnostic analysis and are not fitted to survival outcomes. All four endpoints are reported, with no selected optimal cut-point.
